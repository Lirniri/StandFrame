# Примеры Call Function

[English](README.md) | **Русский**

Вызов функций скрипта вручную из меню Stand: «Отладка > Вызов функции» и список «Вызов функций» у модуля
в «Настройки > Отладка > Модули». Оба видны в режиме отладки.

| Файл | Что показывает |
|---|---|
| `01_by_hand.pluto` | Свой файл с кодом и его вызов в «Вызвать функцию»: правила «Имени функции», поле на каждый типизированный параметр, строгие проверки, результаты |
| `02_arguments.pluto` | Аргументы подробно: вектор, вызов внутри аргумента, `#1` и `#1(>1)` в скобках, команды `asstr`, `asint`, `allasstr()`, `astext`, `allastext()`; запускается как скрипт и пишет в лог, что дают поля |
| `03_module_functions.pluto` | Модуль с функциями всех видов параметров в списке модулей и в Call Function: поле «Вызов», «Добавить» |

## Как запустить

1. `01_by_hand.pluto` — файл с кодом для `Atdar.user_script`. Скопируйте его в `store/AnitaDarin/core/call_function/demo.pluto`
   или напишите в «Отладка > Редактор файлов > Свой код» («Создать файл» `demo`, затем «Добавить строку» для каждой строки).
   Его функции будут доступны как `Atdar.user_script.demo.add` и остальные.
2. `02_arguments.pluto` — обычный скрипт, как [basics/07](../basics/07_parsers_and_colors.pluto): вставьте его строки
   в `on_start` модуля и смотрите лог. Он только читает и ничего не меняет в игре.
3. `03_module_functions.pluto` — модуль: скопируйте его в `src/lib/AnitaDarin/modules/` вместе с манифестом
   `03_module_functions.info.json`, как файлы из [modules/](../modules/README.ru.md). Затем `python build.py sync`
   и перезапуск скрипта.

## 1. Вызвать функцию: имя функции

«Отладка > Вызов функции > Вызвать функцию». Введите имя в поле **Имя функции**; что произойдёт, зависит от того,
чем оно заканчивается:

| Вы вводите | Что происходит |
|---|---|
| `Atdar.user_script.demo.add(5)` | Функция вызывается. Функция вызывается **только** если написана со скобками |
| `Atdar.user_script.demo.add` | Не вызывается, только читается: список **Параметры (2)** показывает каждый параметр с типом и значением по умолчанию (или «Нет значения по умолчанию»), а **Возвращает:** — тип результата |
| `Atdar.user_script.demo.total` | Переменная: её значение на строке **Переменная** |
| `Atdar.user_script.demo{}` | Таблица раскрывается в списке **Значение**, только если в конце написано `{}`: вложенные таблицы — списки, функции в ней можно вызвать, а значения переписать |
| `Atdar.user_script.demo` | Без `{}` таблица только просматривается: функции в ней нельзя вызвать, а значения переписать |
| `toast()` | Короткое имя: последняя часть пути (`util.toast`). При включённом «Использовать короткие имена» сначала смотрится имя из `user/call_function/short_names.json` (`{"ped": "PLAYER.PLAYER_PED_ID"}`), потом функции скрипта, потом Stand |
| `VehicleManager:get()` | Двоеточие вызывает функцию как метод модуля |

Если после функции написать `{}` или после таблицы скобки, скрипт скажет об этом: «это функция: {} не нужны»,
«это таблица: скобки нужны только функциям». «Выбрать функцию» под именем берёт имя из списка (ваши короткие имена,
реестр, функции модуля); выбранная функция записывается со скобками.

У функции с типами в параметрах появляется поле на каждый параметр. Для `function add(amount: int, note: ?string = "x"): int`
в списке **Аргументы** под именем два поля, по одному на параметр, и аргументы, написанные в скобках, попадают в них:
`add(5, more)` заполнит «Число» значением `5`, а «Текст» значением `more`. Что набрано в поле, читается как Lua: `5`,
`true`, `v3.new(1, 2, 3)`, вызовы. Исключение — поле «Текст»: его текст берётся как есть, без кавычек.

| Параметр в коде | Поле | Начинается с |
|---|---|---|
| `int` | Число | значение по умолчанию из кода, иначе `0` |
| `float`, `number` | Плавающее число | значение по умолчанию из кода, иначе `0` |
| `bool` | Логическое значение | значение по умолчанию из кода, иначе `false` |
| `string` | Текст | значение по умолчанию из кода, иначе пусто |
| `vector3` | Трёхмерный вектор | значение по умолчанию из кода, иначе `0, 0, 0` |
| `table` | Таблица | значение по умолчанию из кода, иначе пусто |
| `?тип` | по типу | значение по умолчанию из кода, иначе пусто: аргумент не задан |
| без типа, `int\|string` | Аргумент * | пусто: аргумент не задан |

Проверки строгие, поэтому ошибка видна до запуска функции:

- **Логическое значение:** только `true` или `false` (или вызов). Слово вроде `yes`, число или текст в кавычках — это «нужно true или false».
- **Число:** целое число или вызов, который его даёт: `five`, `"5"` и `2.5` — «нужно целое число». «Плавающее число»
  принимает `2.5`, а `five` — «нужно число».
- **Обязательные:** параметр без `?` и без значения по умолчанию («Текст», «Таблица») нужно задать: «аргумент обязателен».
- **Слишком много:** больше аргументов в скобках, чем у функции параметров — «(amount, note) принимает аргументов: 2, передано: 3».
- **Незакрытые скобки и кавычки** тоже замечаются, как и имя, написанное как вызов, которого нет (`asstrr(#1)`): «'asstrr' неизвестно:
  это не функция, не команда и не короткое имя». Пустое поле — аргумент не задан, и действует значение по умолчанию из кода.

Результаты:

- **Переменная: ...** — то, что вернула функция. Уведомление пишет «имя: выполнено» (или «имя: пусто (nil)», «имя: ошибка: ...» и так далее).
- **Значение (N)** появляется, когда вернулась таблица: записи в виде списков и полей.
- **Глубина таблиц** — сколько уровней вложенных таблиц раскрывается в списке «Значение»; более глубокие остаются строкой `{...}`.
  На больших таблицах держите её небольшой (`Atdar{}` даёт очень много пунктов).
- **Копировать результат** и **Записать результат в лог** кладут весь результат в буфер обмена или в лог.

Другие поля этого же списка: **Вызывать после ввода функции** вызывает сразу после ввода имени, **Вызвать** вызывает
(с выбранным числом миллисекунд это «Вызвать через»), **Цикл** и **Цикл с интервалом** вызывают снова и снова.

## 2. Аргументы подробно

`02_arguments.pluto` вызывает тот же код, что и поля, и пишет в лог, что получилось; заметки ниже — что попробовать в меню.

**Векторы.** Параметр `vector3` — список «Трёхмерный вектор: 1, 2, 3» с целым вектором (**Выражение**), затем полями **x**,
**y** и **z**. Целый вектор — это три числа, `v3.new(1, 2, 3)` или вызов, который даёт вектор:

```
Atdar.natives.entity.get_coords(user_ped())
```

Тогда список показывает «Выражение: get_coords(...)» с полями собственных аргументов вызова и строку «Значения: ...» с тем
вектором, который получился. Ось тоже может быть вызовом (`1, 2, math.floor(3.7)`): она остаётся как написана, а строка
«Значения» показывает, что она даёт.

**Вызовы внутри аргументов.** В поле можно написать вызов, а не только значение: `entities.get_user_vehicle_as_handle()`
в поле «Число». Вызов всегда пишется со скобками, `user_ped()`: слово без них — это текст. Вызов функции с известными
параметрами (`Atdar.natives.entity.get_coords(user_ped())`) становится отдельным списком с полем на каждый аргумент.

**`#N` в скобках.** Скобки «Имени функции» (и поля «Вызов» ниже) говорят, из чего составлен вызов:

| Скобки | Что значат |
|---|---|
| `shout(#1, #2)` | Поля 1 и 2 в таком порядке. Именно это «Имя функции» показывает само, пока вы набираете в полях. Если ввести в скобках `shout(hi, true)`, аргументы попадут в поля, а скобки станут `#1, #2` |
| `is_between(#3, #1, #2)` | Те же поля в другом порядке |
| `util.toast(tostring(#1))` | Вызов со значением поля 1 в качестве аргумента |
| `util.toast(#1(>1))` | В поле 1 записан вызов (например, `user_ped()`), а `>1` говорит, что его аргумент 1 заполнен |
| `add(#3)` | Поля 3 нет: «#3: такого аргумента нет (у функции их 2)» |

Если убрать `#1` из скобок, поле 1 очищается; аргументы, набранные в скобках (`add(5)`), попадают в поля.

**Команды**, которые пишутся только в скобках (это не функции скрипта):

| Команда | Что делает |
|---|---|
| `asstr(#1, #2)` | Каждый аргумент как текст; функция вызывается с текстами: `util.toast(asstr(#1))` с `user_ped()` в поле покажет handle текстом |
| `asint(#1)` | Каждый аргумент целым числом; то, что им не стать, будет названо: «abc нельзя сделать целым числом» |
| `allasstr()` | Все параметры функции текстом, без написания `#N`, с уведомлением о них; затем функция вызывается |
| `allasint()` | То же целыми числами; то, что не число, передаётся как есть |
| `astext(#1)` | Ничего не вызывает: уведомление с именем функции и каждым параметром с тем, что в его поле |
| `allastext()` | То же для всех параметров, без `#N` |

Уведомление у последних четырёх выглядит так: `util.toast(text = hi, bitflags = nil): void`: каждый параметр, что набрано
в его поле (и что даёт вызов там, `text = user_ped(): 123`), затем тип результата. Они идут в уведомления Stand, если включено
«Уведомление в Stand».

## 3. Функции модуля

`03_module_functions.pluto` — модуль `ExampleShop`. «Настройки > Отладка > Модули > ExampleShop > Вызов функций» показывает его
функции (те, что с `set_`, — в «Установщиках», если не включено «Отключить категории для функций»). Каждая функция — список с
**Аргументами**, затем **Вызвать** и остальные настройки.

| Функция | Её поле |
|---|---|
| `set_speed(speed: float = 1.5)` | Плавающее число, начинается с `1.5` |
| `set_open(on: bool)` | Логическое значение |
| `set_caption(text: string)` | Текст |
| `move_to(position: vector3)` | Трёхмерный вектор: целый, x, y, z |
| `sum(values: table)` | Таблица: в поле `1, 2, 3` или выражение, дающее таблицу |
| `tag(name: string, note: ?string = "none")` | Текст и необязательный Текст |
| `count()` | нет: ни списка «Аргументы», ни поля «Вызов», «Вызвать» вызывает сразу |

У функции с параметрами над «Аргументами» есть ещё поле **Вызов**: её имя со скобками, по тем же правилам, что у «Имени
функции» в «Вызвать функцию» (скобки, `#1(>1)`, команды). Набор в нём заполняет поля, набор в полях переписывает его.
Аргументы в скобках режутся по запятым, по одному на параметр, поэтому таблица или вектор — это один аргумент:
`sum({1, 2, 3})` заполнит поле «Таблица», `move_to(v3.new(1, 2, 3))` — «Трёхмерный вектор», `tag(shop)` — «Текст».

Та же функция в Call Function:

- Введите `ExampleShop:sum({1, 2, 3})` в «Вызвать функцию > Имя функции» (двоеточие: модуль — владелец метода). В id модуля
  нет точки намеренно: имя с точкой нельзя было бы отличить от пути по таблицам.
- Или добавьте её в список: «Отладка > Вызов функции > Функции > **Добавить**» `ExampleShop:sum`. Функция появится как
  «1: sum(values): number» со своими полями, «Вызовом» и «Вызвать»; та, что ничего не принимает, `ExampleShop:count`, — кнопка.
  **Очистить** убирает одну по номеру, **Сохранять функции** запоминает список до следующего запуска (только пути, а не то,
  что набрано в полях).

## Правила

- Функция вызывается только со скобками, таблица раскрывается только с `{}`: этого держатся и «Имя функции», и поле «Вызов».
- Пишите типы у параметров (`amount: int`): без них поле называется «Аргумент *» и ничего не проверяется.
- Не называйте поле модуля так же, как поле самого Module (`enabled`, `label`, `text`, `name`...): `ExampleShop` хранит состояние
  в `open` и `caption`.
- Если id модуля будет набираться в пути, делайте его одним словом.
