# StandFrame

[English](README.md) | **Русский**

StandFrame — скрипт для [Stand](https://stand.sh) (GTA V) на Pluto. Он предоставляет основу для скриптов и игровое
меню с профилями, переводами, настраиваемыми командами, уведомлениями и средствами отладки модулей.

## Что реализовано

- **Пакеты меню.** Можно загрузить пакет из `store/<скрипт>/menu/` или скопировать его в ядро через меню. Пакеты
  могут содержать свои фичи, структуру меню, переводы и имена команд.
- **Фичи и модули.** Фичи — действия, переключатели и циклы в меню. Модули — службы скрипта, которые запускаются
  независимо и могут объявлять зависимости. В режиме отладки можно смотреть модули, вызывать их функции и
  перезагружать изменённые файлы.
- **Профили.** Создание, сохранение, загрузка и удаление наборов настроек; при желании — автосохранение.
- **Переводы.** Автоматический выбор языка Stand или выбор другого доступного языка. Можно создавать файлы новых
  переводов, проверять прогресс и перечитывать языковые файлы без перезапуска.
- **Командная строка.** Настройка префиксов и разделителей, переименование команд скрипта и меню, добавление
  псевдонимов и создание пользовательских команд из последовательностей команд Stand.
- **Уведомления и логи.** Настройка места показа уведомлений, стиля ленты игры, изображения, цветов и смайликов по
  уровню. Логи записываются в отдельные файлы по дням.

Встроенное меню ещё разрабатывается. Сейчас в нём доступны некоторые функции для игрока (например, бессмертие,
передвижение и действия со здоровьем, бронёй и выносливостью) и действие для машины; некоторые разделы пока являются
заготовками без фич. Движок обновления также пока не подключён к работающему скрипту: пункты «Обновление» в меню —
заглушки, которые ещё не устанавливают обновления. Подробности: [updater/README.ru.md](updater/README.ru.md).

## Установка и запуск

Требования: Python 3 для скрипта сборки и [Stand](https://stand.sh) для запуска. Проект рассчитан на Pluto 0.13.2.

Из корневой папки репозитория:

```text
python build.py sync       скопировать или обновить файлы проекта в Stand
python build.py watch      синхронизировать сейчас и после изменений в src (остановка: Ctrl+C)
python build.py rebuild    удалить установленный код и скопировать актуальный проект
python build.py status     показать найденную установку
python build.py clean      удалить установленный код, сохранив пользовательские данные
python build.py clean --all
                           также удалить профили, настройки, логи и сохранённые команды
```

По умолчанию файлы копируются в `%APPDATA%/Stand/Lua Scripts`. Для другой папки используйте `--target DIR`, для
выбора имени установки — `--name NAME`. Если установлено несколько копий, укажите `--name`.

`sync` сохраняет имеющиеся пользовательские данные в `store/<имя>/`: `config.json`, `profiles/`, `logs/`,
`commands/` и `user/` (ваши данные, например короткие имена для Вызова функции). `rebuild` удаляет файлы, которых больше нет в проекте, но сохраняет эти данные. Скрипт можно
переименовать в его настройках; сборщик обнаружит установленный файл запуска и продолжит использовать его имя.

После синхронизации запустите или перезапустите скрипт в Stand. В разделе настроек скрипта можно выбрать профиль и
язык, настроить уведомления и имена команд, а через «Загрузить меню» выбрать или скопировать пакет меню.

## Структура проекта

| Путь | Назначение |
|---|---|
| `src/AnitaDarin.pluto` | Файл запуска; по его имени находятся папки библиотеки и данных |
| `src/lib/AnitaDarin/core/` | Загрузчик, профили, переводы, логирование, файловая система, проверки и менеджер модулей |
| `src/lib/AnitaDarin/features/` | Реализация фич и их реестр |
| `src/lib/AnitaDarin/modules/` | Встроенные модули, включая `VehicleManager` |
| `src/lib/AnitaDarin/natives/` | Обёртки игровых нативов, сгруппированные по пространствам имён |
| `src/lib/AnitaDarin/parsers/` | Парсеры цветов, JSON, исходников Pluto и имён команд Stand |
| `src/lib/AnitaDarin/ui/stand/` | Меню Stand, настройки, профили, командная строка и отладка модулей |
| `src/store/AnitaDarin/` | Данные по умолчанию и встроенный пакет меню |
| `examples/` | Пошаговые примеры API, фич, модулей, меню и пакетов |
| `tests/` | Тесты на заглушках API Stand |
| `updater/` | Отдельный движок обновления и генератор манифеста релиза; пока не подключён к скрипту |

## Разработка и тесты

Установите Pluto 0.13.2 (`pluto` и `plutoc` должны быть доступны через `PATH`), затем выполните:

```text
python tests/run.py
```

Тестовый запуск проверяет синтаксис Pluto, имена нативов при наличии локального дампа и запускает тесты на Pluto и
Python. Чтобы выбрать тесты, в имени файла которых есть слово, передайте его после команды, например
`python tests/run.py json`. Подробнее: [tests/README.ru.md](tests/README.ru.md) и
[examples/README.ru.md](examples/README.ru.md).
